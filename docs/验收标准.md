## 二、必须先想清楚的战略问题：你的原创主张是什么
M1~M3 是**复现**，不是贡献：
- M1 复现 Ramsauer et al. (2021) 的等价性——这是别人已经证明过的定理；
- M2 验证你自己实现的 SDE 满足 FDT——这是数值方法的正确性检验，任何做随机模拟的人都要做；
- M3 复现 Scellier & Bengio (2017) 的 EqProp——理论 2017 年就成熟了，MNIST 级别别人也跑过。
这三个里程碑的意义是**证明你的实现是对的**，是入场券，不是论文。**你真正的原创主张只有两个，都在 M4/M5：**
1. **M4 主张**：信息素 τ（含扩散项）是平衡层自由能景观的**慢变量**，且 LTP 阈值门控对应自由能景观的**分岔点**。如果成立，"双权重快慢分离"就从工程直觉升格为热力学结构必然；如果不成立，信息素就该降级为启发式。
2. **M5 主张**：驱动层的熵产生 σ 可以作为**无监督信用信号**替代统计损失，且 σ≥0 由第二定律结构性保证——这是"非平衡热力学作为学习信号"的具体实例化。
这个区分直接决定你的实验设计：**M1~M3 的代码要写成可复用的库，M4~M5 的实验要围绕"能否证伪你的主张"来设计**，而不是围绕"能否跑出好看的曲线"。

## 三、第一周的行动清单
**Day 1~2：M1 落地。** 64 神经元 Modern Hopfield，三个数值检验：
```python
import torch, math
torch.manual_seed(0)
N, n_patterns, beta = 64, 10, 8.0
patterns = torch.randn(n_patterns, N)          # 存储模式
patterns = patterns / patterns.norm(dim=1, keepdim=True)
# LSE 能量: E(ξ) = -(1/β)·logsumexp(β·X ξ) + 0.5||ξ||²
def energy(xi):
    return -torch.logsumexp(beta * patterns @ xi, 0) / beta + 0.5 * xi.dot(xi)
# 检验 (a): 能量单调下降
xi = torch.randn(N) * 0.5
E_prev, traj = energy(xi), []
for t in range(2000):
    # 梯度: ∇E = -softmax(β·Xξ)·Xᵀ + ξ
    grad = -(torch.softmax(beta * patterns @ xi, 0) @ patterns) + xi
    xi = xi - 1e-2 * grad
    E = energy(xi)
    assert E <= E_prev + 1e-9, f"能量上升 at step {t}: {E_prev} -> {E}"   # Go/No-Go M1a
    traj.append(E.item()); E_prev = E
# 检验 (b): 一步更新 ≡ softmax attention
q = patterns[3] + 0.1 * torch.randn(N)
attn_v = torch.softmax(beta * patterns @ q, 0) @ patterns            # 注意力输出
# 能量梯度下降不动点（迭代到收敛）
xi = q.clone()
for _ in range(5000):
    grad = -(torch.softmax(beta * patterns @ xi, 0) @ patterns) + xi
    xi = xi - 5e-3 * grad
print("attention vs 不动点 L2 误差:", (attn_v - xi).norm().item())    # 要求 < 1e-5 (调 β 与步长)
# 检验 (c): 收敛步数 ~ O(log(1/ε))
# 对 ε ∈ {1e-2, 1e-3, 1e-4} 测到达 ||∇E||<ε 的步数，画 log-log，斜率应为对数级
```
跑通后记下三个数：能量漂移、L2 误差、收敛标度斜率。这三个数直接填进 M1 的 Go/No-Go 表。
**Day 3~4：M2。** 在上面的梯度里加 `noise = sqrt(2*T*dt)*randn(N)`，跑 10⁵ 步，测稳态 ⟨‖ξ−ξ̄‖²⟩/(2T·dt)。**这里有一个必踩的坑**：FDT 检验的对象是速度型坐标（⟨v²⟩=T/m），而你用的是过阻尼坐标，正确检验是**位置方差对势曲率的反比关系**（Ornstein-Uhlenbeck 型：⟨δξ²⟩ = T/λ，λ 是平衡点 Hessian 本征值）。写检验脚本前先把这条对准，否则 M2 会假性失败。
**Day 5~7：M3 开工。** MNIST，两层网络，EqProp。梯度余弦相似度检验（EqProp vs BP > 0.99）在 β=1e-3 量级做，β 太小数值噪声会淹没差分。

## 四、写代码前必须定的两个理论细节（文档里还欠着）
这两处不是文档问题，是**实现时绕不开的规格缺口**，现在不定，写代码时会被迫拍脑袋：
**1. σ 的离散定义式。** 文档里 σ = Σ(流量)×(热力学力) 是连续形式。驱动层是确定性的（相位方程无噪声），此时熵产生如何定义？两个候选：
- **候选 A**：把相位方程视为某个周期驱动系统的平均，σ 从相位滑移率定义（Kuramoto 文献里有现成的非平衡 σ 定义，去查 Sakaguchi / Pikovsky 的工作）；
- **候选 B**：放弃严格 σ，用"驱动层对平衡层做的功" W_drive = ∮ J_ij·dθ 的环积分作代理，环积分非零当且仅当系统非平衡。
- **必须选定一个并写进 M5 的验收定义**，否则"σ≥0 恒成立"这条门槛没有可操作含义。
**2. τ 进入平衡层 F 的读法与时标。** F_phere(ξ; τ) 已定（τ 调制势阱深度），但 gate(σ) 门控沉积时，σ 是在哪个时间尺度上算的？合理选择：τ 的一个演化步（慢）对应平衡层 K 步弛豫（快），σ 在每次弛豫收敛后用终态与初态的能量差/路径长度估计。**绝热近似的适用条件（τ 时间常数 ≫ 弛豫时间）要写成显式不等式并进 M4 的验收**：ρ⁻¹ ≫ K·ε，否则快慢耦合会破坏 EqProp 的两相假设。
