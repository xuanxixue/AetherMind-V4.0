## 一、已修复Bug汇总

| Bug | 严重程度 | 问题描述 | 修复方式 | 修复文件 |
|-----|---------|---------|---------|---------|
| **0: Tokenizer严重缺陷** | 🔴 致命 | 自训练BPE初始化错误，256字节基础token缺失，中文全编码为unk | 替换为Qwen2.5-0.5B开源tokenizer (151643词表) | `src/data/dataset.py`, `configs/aethermind4_config.py` |
| **1: 评估phase参数未生效** | 🔴 高 | 评估时传入phase="A"但模型不切换配置，eval_loss包含辅助损失 | evaluate()中临时切换cfg为Phase A，评估后恢复 | `src/training/train_v4.py` |
| **2: Phase C辅助损失权重过大** | 🟡 中 | 辅助总权重3.49是主LM的3.5倍，主导loss波动 | 权重减半，总权重控制在~1.3 | `configs/aethermind4_config.py` |
| **3: 可学习温度被强制覆盖** | 🟡 中 | 每步set_temperature()覆写log_temp，温度自适应失效 | 删除set_temperature调用，通过temperature_override传参 | `src/model/aethermind4.py` |
| **4: 信息素演化未激活** | 🟢 低 | 奖励信号弱(dF归一化分母大)、deposit=0.05 < rho=0.03蒸发、阈值1.5过高 | 奖励缩放×5、deposit=0.12/rho=0.02、阈值降至1.2 | `configs/aethermind4_config.py`, `src/model/evolution/evolvable_weight.py` |
| **5: 启动脚本路径解析错误** | 🟡 中 | cmd中路径含空格导致命令解析错误 | 使用`%~dp0`和引号包裹路径 | `run_inference.cmd`, `train_v4.cmd` |

## 二、修复后的配置参数

### Tokenizer
- **类型**: Qwen2.5-0.5B BPE tokenizer (已下载到 `models_local/Qwen/Qwen2___5-0___5B`)
- **词表大小**: 151643 → 对齐到151680 (128倍数)
- **特殊token**: pad=eos=bos=unk=151643 (`<|endoftext|>`)
- **编码质量**: 中文编码解码完全正确，无unk问题

### 模型配置 (d=384, L=6, h=6)
- **参数量**: ~101M (385.6 MB)，比之前大因为词表扩大
- **Embedding层**: 151680 × 384 = ~58M参数（占比57%）
- **最大序列长度**: 512
- **Batch**: batch=1 × grad_accum=16 = effective_batch=16

### Phase配置
| Phase | 步数 | 说明 | 辅助总权重 |
|-------|------|------|-----------|
| A | 5000 | 纯BP预训练，物理/演化层冻结 | 0.0 |
| B | 10000 | 物理层+信息素渐入 | ~0.5-1.0 (渐入) |
| C | 20000 | 全激活演化+LTP固化+降温 | ~1.3 |

### 信息素演化参数 (Bug4修复)
| 参数 | 旧值 | 新值 |
|------|------|------|
| pheromone_deposit | 0.05 | **0.12** |
| pheromone_rho (蒸发率) | 0.03 | **0.02** |
| consolidate_threshold | 1.5 | **1.2** |
| consolidate_lam | 0.1 | **0.15** |
| reward_scale | 1.0 | **5.0** |
| reward归一化分母 | 1.0 | **0.1** |

## 三、训练启动方式

### 双击启动（推荐）
直接双击运行 `train_v4.cmd`，自动开始全新训练（带--fresh参数）。

### 命令行启动
```powershell
cd d:\AetherMind-Nano3
C:\Python312\python.exe src\training\train_v4.py --fresh --d_model 384 --n_layers 6 --n_heads 6 --max_seq 512 --batch_size 1 --grad_accum 16 --lr 3e-4 --phase_A 5000 --phase_B 10000 --phase_C 20000 --output_dir d:/AetherMind-Nano3/checkpoints_v4_fixed --data_dir d:/AetherMind-Nano3/03_dialogue
```

训练完成后，推理脚本会自动从 `checkpoints_v4_fixed` 目录加载最新checkpoint。
