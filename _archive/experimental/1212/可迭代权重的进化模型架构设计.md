> 写给曦雪。你要的不是 Agent，是**模型**——一个预训练后还能**持续迭代核心权重**的模型。
> 这份文档把"热力学注意力 + 信息素路径网络（物理骨架）"和"Transformer（统计学习层）"焊成一个闭环，并给出落地路径。

## 零、一句话回答

你直觉里的那句话，翻译成技术就是：

> **Agent 的"持续学习"是伪的——权重冻结，学到的东西挂在外部记忆里，关掉上下文就失忆。你要的是让模型在推理时就能把经验写进自己的权重，关掉上下文还认得。**

解法：把模型的权重拆成两层——

| 层 | 本质 | 更新机制 | 时间尺度 | 谁在卷 |
|---|---|---|---|---|
| **快权重 W**（Transformer 主干） | 统计学习 | 梯度下降（BP，需标签/奖励、离线） | 预训练 | GLM/Kimi/DeepSeek 全在这层 |
| **慢权重 τ**（信息素路径） | 物理演化 | 沉积+蒸发+固化（局部、在线、无监督） | 后训练+部署 | **没人在做** |

信息素 τ 从"逐样本激活"升级为"可固化、可持久化的第二权重"——这是让模型**在推理时迭代自己行为**的唯一通道。

## 一、先讲透：为什么市面模型"权重不能迭代"，Agent 是权宜之计

1. **权重 W 是静态张量**，唯一更新通道是梯度下降。梯度下降有三个硬约束：要标签/奖励信号、要反向传播（算全图梯度）、要离线大 batch 重训练。上线后这三样都不具备 → **权重只能冻结**。
2. 冻结的模型会"失忆"（见到的都记不住），于是行业发明了 **Agent 外挂**：RAG、工具调用、外部记忆系统、长上下文。本质是**把记忆挪到模型外面**。
3. 所以 Agent 的"持续学习"是**伪学习**：能力提升发生在上下文/向量库/工具里，模型本身一个字没改。任务一切换、上下文一清空，回到原点。
4. **你要的东西**（生物一直有的东西）：突触可塑性。神经元突触的强度变化（LTP 长时程增强 / LTD 长时程抑制）是**局部、在线、无监督、用进废退**的——不需要"全局梯度下降"这个离线动作。信息素路径网络模拟的正是这一层。

**点睛**：权重 vs 激活的区别，就是模型 vs Agent 的区别。激活逐样本用完即弃；权重持久、改变模型本身。信息素 τ 是唯一"既逐样本更新、又能持久化"的量——所以它是把"学习"升级成"演化"的钥匙。

## 三、核心架构：双权重（快学习 + 慢演化）

```
                       ┌─────────────────────────────────────────┐
   输入序列 x  ────────►  快权重 W：Transformer 主干               │
                       │   (借 CSA/HCA、mHC、MoE、Muon)            │
                       │   预训练学到强通用表征，之后冻结           │
                       │        │  产生 Q/K/V → 能量 E = -Q·K/√d   │
                       │        ▼                                 │
                       │   慢权重 τ：热力学注意力 + 信息素路径       │
                       │   A ∝ exp(-E/T) · τ^β                     │
                       │   τ 用沉积+蒸发+固化在线迭代（非梯度）      │
                       │        │  输出 = Σ A·V                    │
                       └────────┼─────────────────────────────────┘
                                ▼
                            输出 y（含自由能 F、熵 H 反馈）
```

**三个时间尺度**（前一轮已确立，这里落进"双权重"框架）：
- **结构**：Transformer 主干（固定拓扑）；
- **快**：热力学注意力——温度 T 管"这一步怎么选"（探索↔利用），梯度可学；
- **慢**：信息素 τ——"哪条路走过很多次"，非梯度在线迭代，是**可演化的第二权重**。

**耦合点**：`A ∝ exp(-E/T) · τ^β`。E 来自主干表征（统计学习决定"世界长什么样"），τ 是演化记忆（决定"我倾向走哪条路"），T 是温度（决定"我有多愿意试新路"）。三者相乘，把"学习"和"演化"焊死在一起。

## 四、数学：把 τ 写成"可演化的第二权重"

### 4.1 信息素动力学（慢权重更新，非梯度）

```
τ ← (1-ρ)·τ + η·A·r        # ρ 蒸发（用进废退），η·A·r 沉积（奖励门控）
τ.clamp(τ_min, τ_max)
```

r 是信用信号。**上一轮的诚实结论在这里生效**：粗糙 0/1 对错奖励只能凝出"够用但非真"的路。所以这里 r 要升级为**自由能/互信息信用**（见 §4.2），不是笼统对错。

### 4.2 自由能选择压力（演化的方向）

演化不能是随机游走，要有"适应度"。用自由能当选择压力：

```
F = ⟨E⟩ - T·H,    H = -Σ A log A（熵）
演化方向 = -∇_τ F  →  让 τ 往"低自由能 + 保留信息"的方向走
```

这比"对错奖励"密得多：它不仅知道"这步对不对"，还知道"这条路有多确定（熵）、代价多大（能量）"。物理演化和信息论在这里合流。

### 4.3 固化（LTP 长时程增强）：短期记忆 → 长期权重

这是"激活 → 权重"的临门一脚：

```
固化规则（阈值门控）：
  if τ[CLS→j*] 持续超过阈值 θ：
      ΔW_route[j*] += λ·τ[CLS→j*]     # 写入主干（永久权重，可持久化）
      τ[CLS→j*]  ← τ[CLS→j*]·(1-γ)    # 局部衰减，短期记忆让位
```

- **固化后**：这条路由从"信息素（会蒸发）"变成"权重（不蒸发）"——**经验长进了模型身体里**。
- 固化可用 **DeepSeek 的 hash 路由**做索引（高频路径直接 hash 成一个可查表），存储 O(1) 而非 O(N²)。
- 固化的 ΔW 与 **LoRA 低秩子空间同构**：可合并进主干、可卸载、可量化（借 Kimi QAT），不会无限膨胀。

### 4.4 温度退火（探索→利用）

```
T：训练初高（高温=玻尔兹曼分布平=广探索），随固化进程退火到低（聚焦利用）
```

退火和固化是配套的：T 高时 τ 广撒网，找到好路后 T 降下来 + 固化把它焊死。

**这一整套是"物理演化 + 信息论"的闭环，不是统计梯度**——它不需要 BP、不需要离线、可以在推理时逐样本跑。

## 五、三阶段训练管线

| 阶段 | 权重状态 | 更新机制 | 对应行业做法 |
|---|---|---|---|
| **一、预训练** | W 可学，τ=均匀 | 纯梯度（Muon/mHC/MoE 高效训练） | 三家的预训练 |
| **二、后训练** | W 弹性微调，τ 开始固化 | 梯度 + 信息素沉积混合；信用=RL/OPD 式长程奖励 | GLM-5.3 的后训练 RL Scaling |
| **三、部署** | **W 冻结，τ 持续在线演化+固化** | 纯物理演化（自由能选择 + 固化） | **没有对应，我们的核心** |

阶段三是分水岭：市面模型在阶段三的权重是死的；我们的 τ 在阶段三还活着，**每个任务、每个样本都在改变模型的核心行为权重**——这就是"像 Agent 一样持续学习"，但学到的东西长在权重里，不是挂在外头。

## 六、难点与对策（诚实版）

| 难点 | 对策 |
|---|---|
| 灾难性遗忘（学 B 忘 A） | 蒸发=用进废退（弱路径自然消亡）+ 固化保护（A 的高频路径已写死成权重，不受 B 影响）+ 主干弹性约束 |
| 演化方向（凝错路） | 自由能/互信息信用替代粗糙对错（上轮结论的直接应用） |
| τ 存储 O(N²) 爆炸 | 低秩分解 + hash 路由索引 + 稀疏注意力（借 DeepSeek/Kimi） |
| 深网络更新不稳 | mHC 式双随机约束 + τ 的 clamp/归一化 |
| 固化后模型膨胀 | ΔW 与 LoRA 同构，可合并/卸载/量化，设固化预算上限 |

**不吹的边界**：这是架构方向 + 机制内核已验证（PGTT 那套）。从"玩具任务"到"千亿级真·可演化模型"，中间还隔着大量工程——τ 的低秩大规模实现、固化与主干梯度的协同调度、以及"演化到底比纯后训练多带来多少增益"的严格评测，都还没做。但**方向是清的，机制是通的，且正好踩在 DeepSeek 留给 V5 的 Engram 空位上。**

- `pheromone_thermo_transformer.py` = 阶段二/三的 **τ 动力学内核**（沉积/蒸发/自由能/温度退火，已跑通）。

### MVP 实测结果（`evolvable_weight.py`，已跑通）

冻结主干 W，路由能力唯一载体 = τ，对比"固化 vs 不固化"：

| 模型 | 训练后 τ | 操作 | 清空工作记忆后 CLS 指向 |
|---|---|---|---|
| M1 演化模型 | 峰值列6（τ=3.95） | **固化** → 清 τ | **列6（权重 0.804）** ← 记住了 |
| M2 对照模型 | 峰值列6（τ=3.95） | 不固化 → 清 τ | 随机（0.095）← 失忆 |

**结论**：固化把经验写进了主干权重，工作记忆清零后仍保留；不固化就是 Agent 式外挂记忆，清了就没了。这就是"模型（权重迭代）"和"Agent（外挂记忆）"的分水岭。

落地路线：
1. **MVP**：固化机制（τ 超阈值写入主干权重，跨 session 保持，对照"不固化则失忆"）。
2. **接 MoE**：τ 当 expert 路由先验，固化=把高频专家选择写进 hash 表。
3. **接 SNN**：E=脉冲势、τ=突触效能、固化=STDP 长时程增强，喂给你的脉冲主干。
4. **对接 HomesteadLM V2**：自由能最小化当"自我进化"的内在驱动，替换你框架里的人工进化规则。
