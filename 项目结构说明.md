## 一、快速入口（根目录）

| 文件                                                   | 用途                                | 发布时 |
| ---------------------------------------------------- | --------------------------------- | --- |
| `run_inference.cmd`                                  | **推理启动器**（交互对话，已改为相对路径，解压到任意目录可用） | 必需  |
| `requirements.txt`                                   | Python 依赖（torch / transformers 等） | 必需  |
| `推理发布_使用说明.md`                                       | 面向使用者的安装与交互命令说明                   | 必需  |
| `项目结构说明.md`                                          | 本文件，面向开发者/发布者的目录导航                | 必需  |
| `AetherMind监控中心.exe`                                 | 训练监控程序（独立）                        | 可选  |
| `启动监控中心.cmd` / `monitor_gui.py` / `monitor_train.py` | 训练监控辅助（依赖 monitor-app）            | 可选  |
| `training-monitor-skill.zip`                         | 监控技能包                             | 可选  |
