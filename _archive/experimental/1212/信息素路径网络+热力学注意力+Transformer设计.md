# 信息素路径网络 + 热力学注意力 + Transformer：融合模型设计

> 写给曦雪。上次我们做了"热力学+信息论为主、统计为辅"的注意力。这次你要把**信息素路径网络（蚁群/群体智能的 stigmergy）**也并进来。
> 核心洞察：三者恰好占据**三个不同时间尺度**——热力学是"每步怎么选"（快），信息素是"跨步累积的路径记忆"（慢），Transformer 是主干，数学把它们写成一套闭环演化方程。

---

## 一、三者各自负责什么（别重叠）

| 模块 | 角色 | 时间尺度 | 物理对应 |
|---|---|---|---|
| **Transformer** | Q/K/V 投影、残差、FFN、序列主干 | 结构（固定） | 介质 / 场 |
| **热力学注意力** | 每一步按能量做随机选址 | 快（每步） | 温度 T 控制探索↔利用 |
| **信息素路径网络** | 边上的轨迹强度 τ，沉积+蒸发 | 慢（跨步） | 群体记忆 / 突触效能 |
| **数学优化** | 自由能目标 + 温度冷却 + τ 动力学 | 训练 | 变分 + 动力系统 |

关键：vanilla 注意力是**无状态**的（每步重新 softmax）；信息素让注意力变成**有状态**的——τ 把"哪些路好走"跨步记住，因此能自组织出稳定路由。

---

## 二、数学公式（设计的核心）

记号：位置 i,j（含 CLS，共 N+1 个）；头 h；head_dim = d_h。τ、T 都按头独立（也可按层共享省显存）。

### 1. 能量（Transformer + 热力学）
```
E^{(h)}_{ij} = − (Q^{(h)}_i · K^{(h)}_j) / √d_h        # 亲和度→势能，越低越"近"
```

### 2. 信息素（群体记忆，持久缓冲）
```
τ^{(h)}_{ij} ≥ τ_min        # 边 i→j 上的轨迹强度，跨步保存，慢速演化
```

### 3. 信息素调制玻尔兹曼注意力（融合点）
```
A^{(h)}_{ij} = softmax_j [ (−E^{(h)}_{ij} + β·T·log τ^{(h)}_{ij}) / T ]
             = softmax_j [ −(E^{(h)}_{ij} − β·T·log τ^{(h)}_{ij}) / T ]
             ∝ exp(−E^{(h)}_{ij} / T) · τ^{(h)β}_{ij}
```
- `β` = 信息素敏感度（类比 ACO 的 α）。
- 意义：**信息素是加在能量上的乘性偏置**——τ 大的边在能量地形上更"低"，更容易被选中。

### 4. 有效自由能与目标
```
Ẽ^{(h)}_{ij} = E^{(h)}_{ij} − β·T·log τ^{(h)}_{ij}          # 被信息素重塑后的有效能量
F = ⟨Ẽ⟩ − T·H                                               # 玻尔兹曼分布即其最小化解
```
所以信息素不是在注意力之外加东西，而是**重塑了注意力采样的能量 landscape**。

### 5. 信息素动力学（离散时间，慢时间尺度）
```
Δτ^{(h)}_{ij} = η · A^{(h)}_{ij} · r^{(h)}_{ij}             # 沉积 = 使用量 × 信用 r
τ^{(h)}_{ij} ← (1−ρ)·τ^{(h)}_{ij} + Δτ^{(h)}_{ij}           # 蒸发 + 沉积
τ^{(h)}_{ij} ← clamp(τ^{(h)}_{ij}, τ_min, τ_max)
```
- `ρ ∈ (0,1)`：蒸发率（遗忘，防止旧路僵化、维持探索）。
- `η`：沉积强度。
- `r`：信用/奖励。**用法一**（基础）：r=1，按注意力使用量沉积 → 注意力走哪、信息素堆哪。**用法二**（进阶/reward-gated）：r = 任务损失梯度或正确性，让"好路"堆得更多 → 真正的群体强化学习。

### 6. 温度冷却（热力学时间尺度）
```
T^{(h)}(t) = T_0 · exp(−κ t)      # 退火调度，或 log_T 当可学参数用梯度更新
```

### 7. 单步闭环（每层 h，每步 t）
```
Q,K,V = Wq(x), Wk(x), Wv(x)
E      = − QK / √d_h
A      = softmax( (−E + β·T·log τ) / T )        # 热力学 × 信息素
O      = A · V                                  # 统计期望 = 输出；Var = 不确定性
Δτ     = η · A · r ;   τ ← (1−ρ)τ + Δτ ; clamp   # 信息素 Deposit+Evaporate
T      = cool(T)                                 # 冷却
```

### 8. 训练目标
```
L = L_task + λ_H · relu(H − H*) + λ_τ · Reg(τ)
```
- `λ_H` 项：熵目标正则（聚焦但不许塌缩），同上次。
- `λ_τ·Reg(τ)`：对信息素的正则。可选：
  - `−H(τ_norm)` 鼓励路由**集中**（稀疏化好路）；
  - `KL(τ‖uniform)` 防止所有边饱和（保持可探索）；
  - `‖τ‖_1` 控制总信息素预算。

## 三、为什么这样"更好"（涌现性质）

1. **自组织路由**：不同头会自发特化出不同 τ 拓扑（头 A 走语法路、头 B 走指代路），无需手工分配——这是 vanilla 没有的。
2. **两个时间尺度**：快注意力（T，工作记忆）+ 慢信息素（τ，长时记忆），天然对应"当下决策 / 历史经验"。
3. **探索↔利用自动切换**：高温+新鲜 τ（广撒网）→ 低温+集中 τ（锁定好路），比固定 softmax 稳。
4. **自演化钩子**：reward-gated 的 τ 更新 = **只靠奖励信号就能让路由越走越好**，不需要每一步都反向传播。这直接对接你 HomesteadLM 的第四/五阶段（无人工干预的自我进化）。
5. **和你 SNN/MoE 天然兼容**：把 `E` 定义成脉冲发放的"势"、τ 定义成突触效能（STDP：用得多↑、衰减↓、噪声=温度），它就是一个**热力学+群体智能的脉冲路由层**。

## 四、和上次 ThermoInfoAttention 的关系

上次：注意力 = 玻尔兹曼分布（热力学）+ 熵正则（信息论）+ 期望/方差（统计）。
本次：在它外面套一层**状态化的信息素缓冲 τ**，把"选路"从一次性变成"带记忆的演化"。信息论（熵/自由能）依然在，只是自由能里的能量被 τ 重塑了（见 §2.4）。统计（白化、期望、方差）也保留。

## 五、实现要点（见 `pheromone_thermo_transformer.py`）

- `τ` 用 `register_buffer` 持久保存，跨 forward 累积（状态化）；训练时每步 `τ = (1−ρ)τ + η·A.detach()`，detach 让 τ 当"环境状态"而非可微参数（和 ACO 一致）。
- 测试时 `update_pheromone=False`，只读不写，看累积的 τ 是否稳定成一条清晰的路。
- β、ρ、η、κ 都是超参；τ 可做每层共享以省显存（O(N²) 同注意力）。
- 玩具任务用**固定路由**：目标恒等于第 k* 个 token 的值，逼模型学会"CLS 必须走到 k*"。训练后看 τ 的 CLS 行是否在第 k* 列形成尖峰——尖峰=信息素凝出的路径。

## 六、可以马上试的变体

1. **reward-gated 沉积**：r 用"该步注意力是否落在正确路由"或"损失下降量"，看 τ 收敛更快更干净。
2. **每层共享 τ**：省显存，看跨层是否形成一致拓扑。
3. **接 MoE**：τ 当 expert 路由的先验，热力学温度当 exploredness。
4. **接 SNN**：E=脉冲势、τ=突触效能、T=膜噪声，做成脉冲路由层，喂给你的 SNN 主干。

## 七、实验验证（demo：`pheromone_thermo_transformer.py`）

玩具任务：固定路由二分类——目标 = "第 k 个位置的值是否为正"，逼模型学会"CLS 必须走到第 k 个位置"。加了**位置通道**（否则所有 token 不可区分，任务不可学）。对比 vanilla / 纯热力学 / PGTT（信息素+热力学）。

关键结论：
- **信息素凝出单条持久路径**：训练后 τ 的 CLS 行在正确路由列(列6)形成尖峰（τ≈0.88，集中度 11.4，其余≈0.01），即"信息素把正确路焊死成一条清晰轨迹"。
- **准确率**：PGTT 0.998 vs 基线 0.7055 vs 纯热力学 0.6320（seed 42；基线在该种子下欠拟合，更显信息素的状态化记忆价值）。
- **奖励门控是必须的**：无门控、直接按注意力用量沉积 → 早期随机错路被信息素锁死（蚁群停滞），准确率掉到 0.73。改成"仅预测正确时沉积" + 弱沉积(η=0.05) + 蒸发(ρ=0.05) 才稳定收敛到正确路由。强沉积/慢蒸发反而触发停滞。
- 演示用**教师奖励**（只在 CLS→正确边上沉积）把凝聚机制画清楚；真实自演化里把教师信号换成"预测正确性 / 损失下降量 / 价值信用"即可（seed 42 预测正确性版也达到 ~0.98）。

一句话：热力学管"这一步怎么选"，信息素管"哪条路走过很多次"，两者用 `A ∝ exp(−E/T)·τ^β` 严丝合缝焊在一起，形成带记忆的自组织路由。

## 八、真实自演化验证（无 oracle 教师奖励）—— `pgtt_self_evolution.py`

第七节用的是**教师奖励**（oracle，只在 CLS→正确边上沉积）把凝聚机制画清楚。这一节把它拿掉，验证"真实自组织"到底行不行：模型**不被告知正确路由在哪**，只靠自己的信用信号 r 当奖励，信息素在预测对时沉积、错时蒸发。

**信用信号三档**（核心对照）：
- `hard`：r = (pred>0)==y，粗糙 0/1，只知道"这步对不对"
- `soft`：r = P(正确类别) ∈ (0,1)，连续，知道"对得多准"
- `soft_center`：r = P(正确)−0.5，零中心化，对的路加、错的路反向撤

**消融基线**：deposit=0（τ 退化为均匀 → 等价纯热力学注意力）。

**实验设置**：7 个种子(0,1,2,3,7,11,42)，每种子 200 epoch，B=128，K=5→正确列=6，报告准确率 / τ集中度 / 尖峰是否落在正确列 / 多头一致性。

| 配置 | 测试准确率 mean(min/max) | τ集中度 mean(max) | 真路由命中 | 多头一致 |
|---|---|---|---|---|
| ① 纯热力学(关信息素) | 0.6404 (0.53/0.89) | 1.00 (1.00) | 0/7 | 0/28 |
| ② hard 0/1 | **0.7231** (0.62/1.00) | 2.64 (5.70) | 0/7 | 3/28 |
| ③ soft 连续 | 0.7074 (0.63/0.99) | 2.72 (6.61) | **1/7** | 4/28 |
| ④ soft_center | 0.7186 (0.59/0.99) | 1.76 (4.27) | 0/7 | 0/28 |

seed 42 轨迹（头0 从 CLS 出发的 τ 集中度→峰值列）：hard `1.50→列2`、soft `1.33→列3`、soft_center `1.00→列0`，始终没落到正确列 6。

### 诚实结论

1. **自组织成立（✓）**：只要 deposit>0，τ 就从均匀 1.00 凝到 2.6~2.7（最高 6.61）。信息素**无需任何 oracle** 就踩出了持久路径，证明状态化的 stigmergy 路由确实会自发生成。
2. **准确率增益（✓）**：纯热力学 0.64 → 加信息素 0.72。信息素提供的"跨步路径记忆"确实比无状态注意力更稳，和第七节 oracle 版结论同向。
3. **真路由锁定失败（✗，但符合预期）**：命中率 hard 0% / soft 14% / soft_center 0%。凝出的路径**没落在真实因果列**，浓度也远低于 oracle 版的 11.4（仅 2.6）。

**为什么**：本玩具任务标签只依赖单个 token，存在**退化解**——模型用任意一条"够用"的路线就能过 0.5，0/1 信用只知道"这步对"，不知道"是哪条路由换来的对"。蚁群于是巩固了一条"够用但非因果真相"的路。这是**自组织系统的真实性质，不是 bug**：reward-gated stigmergy 找到的是"局部有用的路"，不保证是"地面真理因果路"。

### 下一步（让无监督锁定真路由）

- **更密的信用信号**：把 r 换成互信息 / 因果影响（如"遮住该路由后预测崩多少"），而不是笼统的对错。这正接第六节 §1 的 reward-gated 与"互信息预训练"方向。
- **任务无退化解**：设计"成功 ⇔ 必须走真路由"的任务（如多跳推理、路由错误则必错），让任何成功都只能来自真路由，蚁群自然焊死真路。
- **冷启动用 oracle、热运行撤掉**：训练初期给少量教师信号把 τ 拉正，之后再切纯自演化，兼顾收敛速度与无监督部署。

一句话：PGTT 的"自组织路由"是真的不假，但在粗信用信号下它会收敛到**一条够用的路**而非**正确的路**——要用它做因果级自演化，信用信号必须更密，或任务本身不能有退化解。
