## 摘要（结论先行）

**三个方案可以结合，而且不是并列拼装——它们是同一个物理对象在不同维度上的投影。** 这个物理对象是**传播子（格林函数）G(x−x')**：

| 方案 | 解决的维度 | 物理身份 |
|------|-----------|---------|
| A：信息素相对偏移核 | **表示**（状态怎么存） | 传播子的离散化 |
| B：谱低秩 / 线性注意力 | **计算**（状态怎么算） | 传播子的谱截断 |
| C：扩散场演化 | **演化**（状态怎么变） | 传播子的连续动力学 |

三者共享同一条数学主线：**平移不变性 → 本征展开 → 只保留少数长程模**。结合后得到一套自洽的"物理场式演化层"，同时解决三件事：O(S²) 存储、O(S²) 计算、上下文滑动错位。

## 一、为什么能结合：三个方案本是同一副骨架

先看三个方案各自的"病根"：

1. **A 治存储**：`τ[i][j]` 用绝对坐标，O(S²) 且平移时错位 → 改成相对坐标 `τ[i−j]`。
2. **B 治计算**：注意力 `A=softmax(−E_eff/T)` 是 O(S²) 的全对全传播 → 用核分解截断成 O(S·r)。
3. **C 治演化**：τ 的更新是逐格子的离散规则 → 改成连续扩散方程。

表面看是三个独立改动，但它们指向**同一个隐藏问题**：V4 的演化层一直在用"绝对坐标下的离散格子"，而物理世界用的是"相对坐标下的连续场"。A、B、C 分别把这个场的**表示、计算、演化**三个侧面纠正过来。因此它们天然可叠加，叠加后恰好拼成一个完整的物理场模型。

## 二、统一数学骨架：传播子与本征展开

### 2.1 传播子 / 格林函数

物理中，一个在 x′ 的"源"在 x 处产生的"响应"，由格林函数描述：

$$L\,G(x, x') = \delta(x - x')$$

其中 L 是系统的线性算子（如库仑势的 ∇²、热传导的 ∂/∂t − D∇²）。核心性质是**平移不变**：

$$G(x, x') = G(x - x')$$

响应只依赖坐标差。这正是"相对坐标"的数学定义。

### 2.2 平移不变 → 本征函数是平面波

平移不变算子 L 的本征函数恒为平面波（卷积定理的谱版本）：

$$L\,e^{ikx} = \lambda(k)\,e^{ikx}$$

因此 G 对角化于傅里叶基：

$$G(x - x') = \sum_k \frac{1}{\lambda(k)}\, e^{ik(x-x')}$$

**关键含义**：任何"只依赖相对关系"的量，都可以在傅里叶/谱基下完全解耦成独立模式。

### 2.3 低秩 = 谱截断

上面的求和里，若 |λ(k)| 随 k 增长（短程模 λ 大、贡献小），则真实动力学被**少数低阶模（小 k，长程）主导**。只保留前 r 项：

$$G(x - x') \;\approx\; \sum_{n=1}^{r} g_n\, \varphi_n(x)\,\varphi_n(x')^*$$

这就是**低秩分解**。线性注意力的核分解 `A ≈ φ(q)ᵀφ(k)` 正是它的离散实例——**方案 B 不是工程技巧，是谱截断的物理必然**。

### 2.4 扩散 = 各模独立衰减

扩散方程在傅里叶域的解：

$$\hat\tau(k, t) = \hat\tau(k, 0)\; e^{-D k^2 t}$$

每个空间频率**独立指数衰减**：低频率（长程关联）衰减慢被保留，高频率（短程噪声）衰减快被抹平。这正是"长程结构自发涌现、短程噪声自然消去"的机制——**方案 C 是方案 A/B 那个相对场在时间维上的自然演化**。

> 一句话串起三者：**传播子（G(x−x′）) 的表示是相对核（A），计算是谱低秩（B），演化是扩散（C）。**

## 三、三方案在统一骨架下的角色

### 3.1 方案 A = 表示的离散化

把连续传播子落在 token 链上，用相对距离桶离散化：

$$\tau[i][j] \;\longrightarrow\; \tau_{\text{rel}}[d],\quad d = \text{clip}(i-j,\,-k,\,k)$$

`tau`/`consolidated` 从 `(h,S,S)` 降为 `(h,2k−1)`。这是把"绝对坐标矩阵"替换为"相对坐标核"，恢复平移对称性。

### 3.2 方案 B = 计算的谱截断

注意力 A 是 query 到 key 的传播幅，用核技巧做低秩：

$$A(q,k)\;\approx\;\phi(q)^\top\phi(k)$$

计算链从 `q·kᵀ·v`（O(S²)）改写为 `φ(q)·(φ(k)ᵀ·v)`（O(S·r)）。相当于只保留传播子的前 r 阶本征模。

### 3.3 方案 C = 演化的连续化

把 τ_rel 的更新从"逐格子的沉积+蒸发"升级为离散扩散：

$$\tau_{\text{rel}}^{t+1} = (1-\rho)\,\tau_{\text{rel}}^{t} \;+\; D\,\text{Lap}(\tau_{\text{rel}}) \;+\; \eta\cdot\text{source}(A)$$

三项分别对应：蒸发（衰减）、扩散（平滑/长程保留）、沉积（注意力热点注入）。

## 四、结合后的完整架构

### 4.1 数据流

```
input_ids (B,S)
   │
   ▼
PGTA 注意力（方案B：核低秩，O(S·r)）
   │  A ≈ φ(q)ᵀφ(k)        ← 计算层：谱截断
   ▼
有效能量 E_eff = E − βT·log τ_rel − T·C_rel
   │        ↑                                    ↑
   │        │ 相对核（方案A，O(k)）               │ 固化相对核（方案A）
   ▼
信息素演化（方案C：扩散场）
   τ_rel^{t+1} = (1−ρ)τ_rel + D·Lap(τ_rel) + η·source(A)
   │
   ▼
固化（LTP）：τ_rel 超阈值 → 写入 C_rel（仍是 O(k)，平移不变）
```

### 4.2 核心公式（结合态）

表示（A）+ 演化（C）：

$$\tau_{\text{rel}}[i\!-\!j] \xleftarrow{\;\text{diffuse+deposit+evaporate}\;}\ \tau_{\text{rel}}[i\!-\!j]$$

计算（B）：

$$\text{attn\text{-}out} = \phi(q)\,\big(\phi(k)^\top \odot \tau_{\text{rel}}\big)\,v$$

三者共享同一组**相对桶索引**与**同一组谱基**，不再是三套独立机制。

## 五、结合后的收益与量化

| 指标 | 现在（绝对 S×S） | A 单独 | **A+B+C 结合** |
|---|---|---|---|
| τ/C 存储 | O(S²) | O(1) | **O(1)** |
| 注意力计算 | O(S²) | O(S²) | **O(S·r)** |
| S=4096 显存 | ~22.5 GB | ~16 GB | **< 1 GB** |
| 平移不变性 | ✗ 错位 | ✅ | ✅ |
| 演化鲁棒性（短程噪声） | 弱 | 中 | **强（扩散自动去噪）** |
| 物理自洽（与朗之万相对相位一致） | ✗ | 部分 | ✅ |

**三层协同的额外收益**：A 让 B 的核分解有了平移不变的基底，B 的谱截断天然压制了 C 里扩散要处理的短程噪声，C 的扩散又反过来让 A 的相对核在时间上稳定——三者互相增强，不是三个独立补丁。

## 七、风险与注意点

1. **核近似的精度**：`φ(q)ᵀφ(k)` 对 softmax 是近似，需要选好核（如 Performer 的随机特征、或正定核），并在生成质量上回归验证。
2. **相对核丢失绝对位置**：纯 `τ[i−j]` 对"需要精确位置"的任务（如引用第 5 个 token）能力下降，可保留少量绝对偏置做混合。
3. **扩散与沉积的平衡**：D 太大把沉积也抹平了，D 太小退化回离散版，需要调优。
4. **阈值固化在相对核上的语义**：`τ_rel[d] > θ` 表示"某种相对距离的路径反复被强化"，固化的物理含义从位置转向关系，需重新校准 θ。

---

## 八、结语

V4 要回答的问题是"模型能否在部署后继续长脑子"。之前的实现把"脑"里的经验写在绝对坐标的格子里，既耗 S² 又漂移。这份结合的方案把经验放回它该在的地方——**相对坐标上的场**。

这不是模仿生命（突触、蚁群只是表象），而是直接运行物理法则：**传播子给表示，谱截断给计算，扩散给演化，三者由平移对称性统一。** 真实世界的复杂性，正是这种简单相对规则在大量组合下的涌现。V4 的演化层，应当成为这样的一个物理场。

### 9.2 推理注意力层的三方案落地

`PheromoneThermoInference` 与训练版 `PheromoneThermoAttention` **接口完全兼容**（同签名 `forward(x, temperature_override=T)`，返回 `(out, stats)`），只改存储与计算：

- **方案 A（表示）**：`tau` / `consolidated` 从 `(h, S, S)` 变为 `tau_rel` / `consolidated_rel` `(h, 2k−1)`（k=64 默认）。相对偏置通过相对桶索引 gather 回 `(h,S,S)` 参与有效能量。
- **方案 B（计算）**：默认用「窗口掩码」（`|i−j| > k−1` 置 −∞），只算窗口内交互，体现物理局域性。另保留 `use_low_rank=True` 的 ReLU 特征映射线性注意力（实验性，O(S·r)）。
- **方案 C（演化）**：`step_pheromone` 增加一维扩散项 `D·Lap(τ_rel)`（二阶差分，边界零流），长程结构保留、短程噪声抹平。

### 9.3 架构切换方案（train ↔ inference）

**核心权重 W 完全复用，只有 τ/C 的表示与注意力计算分支不同。**

```
训练架构（AetherMind4, arch_mode='train'）
   └─ PheromoneThermoAttention：绝对 τ/C (h,S,S)，softmax(QKᵀ + τ/C)
                    │  权重迁移（convert_train_to_inference.py）
                    │  · Wq/Wk/Wv/Wo/FFN/LN/embedding/lm_head 直接复制
                    │  · τ/C (h,S,S) 对角平均 → τ_rel/C_rel (h,2k−1)
                    ▼
推理架构（AetherMind4, arch_mode='inference'）
   └─ PheromoneThermoInference：相对 τ_rel/C_rel (h,2k−1)，softmax + 相对偏置 + 窗口掩码
```

切换三要素：
1. **参数层 W**：`copy_` 直接复用，无需映射（数学意义完全一致）。
2. **表示层 τ/C**：绝对→相对「对角平均」压缩（`abs_to_rel`），长程窗口内精确、窗口外截断符合物理局域性。
3. **状态层（预热校准）**：加载后冻结 W，跑 N 步自由能驱动的信息素演化，让相对 τ 重新松弛适配新计算图。

### 9.4 关键实现决策：方案 B 用窗口掩码而非纯低秩

原报告 3.2 节规划的「低秩核 `φ(q)ᵀφ(k)`」在实现时改为「窗口掩码」，原因：

相对位置偏置 `bias[i−j]`（方案 A 的核心）在数学上**无法分解进核空间** `φ(q)ᵀφ(k)`；且相对核 τ_rel 只在 `|i−j|≤k` 有意义，**天然就该窗口化**（平移不变性 → 局域性的物理必然）。因此窗口掩码是比低秩更正确的实现；`use_low_rank` 作为可选开关保留，标注实验性。
